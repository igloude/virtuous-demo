## Why this matters

`docs/components/button.md` documents `loading` (row and usage bullet). `ButtonProps` has no such prop — `src/components/Button/Button.tsx:7-14` declares only `variant`, `size`, `fullWidth` on top of native button attributes, and `grep -rn loading src/components` returns nothing. This violates the repo's own rule (README.md:25: "Every component doc's Props table must match the component's exported `*Props` interface"). A stale example is training data for the wrong pattern. If the DS owner wants `loading`, that is a **source** change and a separate DS work item; this plan makes the docs truthful now.
